Cómo publicar Ánima 🔮

Guía paso a paso para hacerlo tú sola · Gratis · Sin programar
Paso 1

Crea tu cuenta en GitHub

GitHub es donde van a vivir los archivos de Ánima. Es gratis.

github.com → Sign up

Usa tu email, elige un usuario (ej: samanda-anima) y crea tu cuenta.

💡 Tip: El nombre de usuario que elijas va a aparecer en el link de tu app — elige algo bonito.
Paso 2

Crea un repositorio nuevo

Un repositorio es como una carpeta donde viven tus archivos.

Una vez dentro de GitHub:

1. Toca el botón verde "New" o "+" arriba a la derecha

2. En Repository name escribe exactamente: anima

3. Marca la opción "Public"

4. Toca "Create repository"

💡 Importante: Debe llamarse exactamente "anima" en minúsculas para que el link quede bonito.
Paso 3

Sube todos tus archivos

Dentro de tu repositorio recién creado:

1. Toca "uploading an existing file" o el botón "Add file → Upload files"

3. Abajo escribe en el campo "Commit changes": Primera versión de Ánima

4. Toca "Commit changes"

Paso 4

Activa GitHub Pages

Esta es la magia — convierte tus archivos en un sitio web real.

1. Ve a Settings (arriba en tu repositorio)

2. En el menú izquierdo busca "Pages"

3. En Source selecciona "Deploy from a branch"

4. En Branch selecciona "main" y carpeta "/ (root)"

5. Toca "Save"

⏳ Espera 2-3 minutos y refresca la página. Aparecerá tu link.
Paso 5

¡Tu app ya está viva!

Tu link quedará así:

https://TU-USUARIO.github.io/anima/anima_completo.html

Comparte ese link con tus primeras usuarias. En el celular, al abrirlo en Chrome o Safari, van a ver la opción "Agregar a pantalla de inicio" — y se instala como app. 🎉

💡 Para tener un dominio propio como anima.mx (~$300 MXN/año en namecheap.com o godaddy.com), lo conectas en esa misma sección de Pages → Custom domain.
